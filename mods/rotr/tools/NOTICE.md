The Clickteam Install Creator 2.0.0.40+ parsing in `import_release.py` was
adapted to Python from the file format implementation in
[cicdec](https://github.com/Bioruebe/cicdec), by William Engelmann.
See `cicdec-LICENSE.txt` for its BSD 3-Clause copyright and license notice.
The importer is restricted to the verified ROTR 1.85 package; it is not a
general-purpose installer extractor.
