# China H-20 Bomber

The formerly disabled Aurora is buildable in China Airfield slot 5 after a
Propaganda Center is constructed. It is unavailable in the USA Airfield menu.
Its definition now lives in `Object/China/Aircraft/H20Bomber.ini`.

The legacy `AmericaJetAurora` object identifier and command set are retained for
existing map/script references. The display name and build tooltip identify it
as the H-20 Bomber. Original Aurora models, scale, sounds, effects, and combat
behavior are reused. This is a fictional ROTR interpretation, not a simulation
of the real H-20 stealth bomber program.

- Health: 80; cost: $2,500; build time: 30 seconds.
- Payload: one 400-damage bomb, radius 20, attack range 300.
- Speeds: cruise 180, attack 480, return 150; flight height 100.
- Reload: 5 seconds at the airfield.
- Standard AirplaneArmor, existing Aurora attack-run protection, no stealth.
- USA Advanced Training and Countermeasures cameos/behaviors and the upgraded
  Countermeasures armor set are removed. No China armor upgrade is added.

Run `python3 mods/rotr/tools/check_h20.py` for build-menu/reference checks and
lossless BIG packaging checks. A dedicated GitHub Actions workflow runs it for
PRs targeting `rotr-base`. In-game China construction, parking, attack protection,
return/reload, audio, and combat balance still require manual testing with the
original Zero Hour assets. The imported manifest remains the original release
baseline; it is not regenerated for development edits.
